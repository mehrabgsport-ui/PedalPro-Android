# PedalPro Native RC39 (2.0.0-native-rc39 · 83)

## متن تغییرات قابل درج در کافه‌بازار
- اصلاح نمایش لوگوی اصلی پدال‌پرو در صفحه آغازین با کیفیت بهتر و پس‌زمینه شفاف.
- اصلاح حالت کم‌مصرف: پس‌زمینه مشکی OLED تنها برای پنل‌ها و دکمه‌های صفحه رکاب‌زنی فعال؛ حفظ ظاهر قبلی صفحه خانه و منوهای دیگر.
- رفع مشکل قرار گرفتن کارت‌ها و مطالب اسکرول‌شونده روی هدر ثابت.
- نمایش واضح‌تر خط مسیر ثبت‌شده با حالت فیروزه‌ای نئونی در وضعیت AMOLED.
- بهبودهای پایداری و سازگاری نسخه بومی اندروید.

## وضعیت انتشار
این نسخه صرفاً برای نصب و ارزیابی کاربر ساخته شده است. **هیچ ارسال، Commit یا انتشار در بازار مجاز نیست مگر تأیید صریح مالک پس از تست RC39**. Workflow قدیمی RC38 غیرفعال شده است. کد نسخه 83 است. شاخه native/web-parity و PR #29 Draft باقی می‌ماند.

## محدودیت‌ها
- دسترسی آزمایشی روی گوشی واقعی هنوز لازم است: نمایش لوگوی شفاف، اسکرول صفحه خانه، تغییر OLED روشن/خاموش، ثابت‌ماندن نقشه و تداوم ثبت GPS.
- این تغییرات در Backend یا سایت تولیدی اعمال نمی‌شوند.
- بهبود کیفیت لوگو از خود طرح رسمی 192px استفاده می‌کند؛ بازطراحی برند صورت نگرفته است.
- انتشار مستقیم قبلی در پیشخان با HTTP 400 در مرحله upload رد شده؛ تا تأیید این نسخه تلاشی برای انتشار مجدد انجام نمی‌شود.
