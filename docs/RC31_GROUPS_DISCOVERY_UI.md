# RC31 group discovery interface
- Homepage quick tile "گالری" replaced with "گروه‌ها", while preserving the gallery elsewhere in the app.
- Native searchable group/event discovery screen using existing authorized bootstrap data only; filters private groups unless the current user is a member or creator.
- Existing club member list, group chat and event details can be opened from the hub.
- **New group creation, invitations, invitation notifications, group-specific chat, group-level points and rankings remain BLOCKED** until new authenticated PHP/MySQL endpoints are safely implemented and staged. This UI does not fabricate those endpoints or claim their availability.
