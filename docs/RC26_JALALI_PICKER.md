# RC26 Jalali date/time picker
- Shared native Persian year/month/day wheel selection, optional 24-hour Iran-local time and Gregorian server payloads.
- Wired to program creation/editing, challenge dates, and retrospective group join time.
- Preserves PHP date field format, does not migrate existing timestamps.
- Not yet wired to every date-bearing legacy form or website; on-device selector and DST/UTC data acceptance remain to be tested.
